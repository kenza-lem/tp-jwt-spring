# Captures personnelles Postman

Ces cinq captures sont fournies par l’utilisatrice, sans modification des résultats.
Voir [le compte rendu](../docs/tests-postman.md).

- 01-inscription.png : utilisateur créé, 200 OK.
- 03-hello.png : message protégé, 200 OK, token masqué.
- 04-profil.png : profil connecté, 200 OK, token masqué.
- 05-acces-refuse.png : profil sans token, 401 attendu.
- 06-runner.png : 20 tests réussis, 0 échec, 0 erreur.

La capture de connexion contenant le JWT complet n’est pas incluse. La réussite
de la connexion est visible dans le bilan du Runner. Les preuves automatiques
antérieures restent archivées dans docs/archives/avant-partie2/.
